# 의도적 의역 메모

## 허용 범위

- 직역하면 한국어 문장 호흡이 지나치게 어색할 때
- 화자의 계급, 감정, 위협 강도를 한국어에서 더 자연스럽게 드러낼 필요가 있을 때
- 시대감은 살리되 의미 없는 고어를 줄여 읽기 흐름을 개선할 때

## 금지선

- 원문에 없는 정보 추가
- 인물 관계나 사건 강도를 바꾸는 과도한 재해석
- 현대 슬랭, 가벼운 인터넷식 구어체, 캐릭터 붕괴

## 실전 힌트

- 대사문은 "뜻의 정확성"과 "입에 붙는 말투"를 함께 봅니다.
- 설명문은 정보 순서를 조정해도 되지만, 고유명사와 인과관계는 유지합니다.
- 기도문, 선서문, 위협문은 어조가 중요하므로 지나치게 평평해지지 않게 합니다.

## 총회 장면 메모

- 총회(Thing) 장면의 법·의례 용어는 북유럽 관습의 질감을 살리되, 첫 등장에서는 기능 설명을 함께 둡니다.
- `holmgang`, `nithingr` 같은 용어는 첫 등장에 한해 `홀름강, 곧 죽음의 결투`, `니딩그, 곧 비겁자이자 사람 이하의 자`처럼 음역과 뜻풀이를 병기할 수 있습니다.
- 총회 판결문과 공개 연설은 직역 순서를 그대로 따르기보다, 수사와 절차가 살아나도록 한국어 호흡에 맞게 재배치합니다.

## 군사 임무 용어 메모

- 공성전 주변 `foragers`는 기본적으로 `징발병`으로 옮깁니다.
- 이 용어는 단순 사냥꾼이나 정찰병보다, 적진 바깥에서 식량과 물자를 긁어모으는 병력의 성격을 더 잘 드러냅니다.
- 다만 문맥이 실제 수렵이나 순수 정찰에 가깝다면 다른 번역 가능성을 다시 검토합니다.

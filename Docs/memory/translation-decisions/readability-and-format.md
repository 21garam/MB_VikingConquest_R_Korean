# 가독성·형식 메모

## 플레이스홀더

- `{s1}`, `{reg1}`, `%d`, `^^`는 의미 파악의 힌트로만 사용하고 구조는 보존합니다.
- 문장 순서를 바꾸더라도 플레이스홀더의 역할과 개수는 유지합니다.

## 문장 호흡

- UI와 메뉴는 짧고 즉시 이해되는 문장을 우선합니다.
- 대화문은 한 문장에 정보가 너무 많이 몰리면 자연스러운 위치에서 끊습니다.
- 반복되는 호칭이나 군더더기 연결어는 한국어에서 어색하면 줄일 수 있습니다.

## 가독성 보정

- 지나치게 긴 나열문은 한국어 어순에 맞게 재배치합니다.
- 의미를 해치지 않는 범위에서 중복 어휘를 정리합니다.

## 공개 연설·판결문

- 공개 연설은 체면과 선동의 리듬이 살아나게, 판결문은 짧고 단정한 절차 문장으로 정리합니다.
- 반복 정보는 줄일 수 있지만, 고발 대상·증거·판단 순서는 흐트러뜨리지 않습니다.
